Firefox 扩展 · Joget DX 9

Joget Skin

给 Joget DX 9 用的个人扩展：整理 Builder 和 userview 界面，并加上一些好用的工具。不在 AMO 公开目录上架，用签过名的 xpi 自己分发。

下载 1.4.1 签名包（.xpi） 所有版本 安装说明 更新日志 仅日志 源代码

安装

  1. 下载上面的签名包（或到 Releases 选一个版本）。
  2. 在 Firefox 打开 about:addons → 齿轮菜单 → 「从文件安装附加组件」，选这个 .xpi 文件。
  3. 第一个会自动更新的版本是 1.4.1。如果现在装的是更早的版本，需要按上面的步骤再装一次 1.4.1 或更新的签名包。

自动更新

装好带 update_url 的签名包之后，Firefox 大约每 24 小时会查一次更新清单，发现更高版本就自动下载并替换。也可以在 about:addons 的齿轮菜单里点「检查更新」，马上检查一次。

从 about:debugging 临时加载源码文件夹适合开发，不会自动更新，Firefox 重启后也要重新加载。

给 Firefox 看的更新清单：updates.json。

更新日志

Joget Skin 的用户可见变更，按版本从新到旧排列。日期为马来西亚时间（Asia/Kuala_Lumpur）。

1.4.1 2026-11-22

第一个可通过 Firefox 自动更新的版本。需要先手动安装这一版的签名 xpi；更早的安装不会自己升上来。代码提交于 2026-11-21，签名并发布于 2026-11-22。

新增

  • 自托管自动更新：在 manifest.json 里加入 update_url，指向 https://noowxela.github.io/joget-skin/updates.json。装好签名包后，Firefox 大约每 24 小时检查一次；也可以在 about:addons 的齿轮菜单里点「检查更新」。
  • 一键发版脚本 release.sh：unlisted 签名、创建 GitHub Release、发布更新清单和本站页面。
  • 项目 GitHub Pages 提供安装说明和本更新日志。

改进

  • 从 about:debugging 临时加载源码文件夹仍然适合开发，但不会走自动更新，Firefox 重启后也要重新加载。

1.4.0 2026-11-21

新增

  • Process Builder 可以导出当前流程，并导入到另一个 app。
  • 工具栏在快捷键按钮后面增加「⬇ 导出此流程」和「⬆ 导入流程」。
  • 导入前会弹出确认框，列出：被改名的参与者、本地缺少的表单和插件、导出时被清空的密码类字段、需要你检查的子流程。
  • 导入不会自动保存，检查后请自己按 Save。
  • 导出时按字段名清空敏感值；确认框会列出每一个被清空的字段。

改进

  • 新流程 id 的后缀跟 Joget 自带的 Clone 一样，是 _2（例如 process1_2），导入结果与克隆一致。
  • 如果本地缺表单，Joget 会拒绝保存，需要先把表单复制过来。
